项目概览

面向泰和污水厂系统（26 座上游泵站，合计设计能力 40.5 m³/s），构建以污水厂为调控核心的"厂前"水量水质超前感知与协同预警框架：融合管网液位、泵站运行、在线水质与降雨驱动，实现进厂流量与 COD/氨氮负荷的 1~3 小时超前预测，驱动四级预警与泵群协同调控，并以概化 SWMM 物理模型在环验证调度策略。

四层数据战略：破解「无泰和真值」困境

  1. 官方静态骨架：组委会 Date1 泰和污水厂 + 26 泵站配泵能力、服务片区与拓扑；
  2. 真实外部驱动：上海市水务局「水情信息」52 站 10 分钟级雨量/水位（2021–2025，约 1150 万行）；
  3. 国际真实代理：Köln-Weiden 厂-网-雨、Graz、BSM2 等 17 类公开数据集（约 280MB），为方法有效性提供真实数据背书；
  4. 物理概化模拟增广：真实降雨驱动的旱天双峰 + RDII + 输送延迟 + 初期冲刷 + 雨天稀释 + 毒性冲击事件。

可复现工程

仓库含 7 项单元测试（模拟器质量守恒 / 雨型峰位 / 特征无泄漏 / 预警阈值 / SWMM 构建等）、GitHub Actions CI 与 requirements-lock.txt 依赖锁定。最小复现链路：

pip install -r requirements.txt
python -m pytest tests -q                       # 单元测试
python -m src.data.shanghai_rain                # ① 官方雨量数据融合
python -m src.simulation.generate --days 92 ...  # ② 实测降雨驱动场景
python -m src.models.forecast --dataset taihe   # ③ 超前预测
python -m src.control.warning                   # ④ 四级预警
python -m src.swmm.build_inp && python -m src.control.rolling_opt  # ⑤ SWMM 在环调度
streamlit run deliverables/demo/app.py          # ⑥ 数字孪生看板

诚实性与合规声明

  1. 泰和厂-网时序数据为「官方静态骨架 + 上海实测降雨驱动」的物理概化模拟，非泰和实测；
  2. 方法有效性以 Köln-Weiden 等国际真实厂-网-雨公开数据集背书；
  3. SWMM 模型为概化参数（未经泰和实测率定），调度结论价值在于策略间相对比较而非绝对数值；
  4. 预警调控效益为模拟场景推算，非现场实测效益；雨预报实验为理想/含噪构造输入，非业务预报实测性能；
  5. 异常分类结果基于模拟冲击事件（测试段仅 1 次），仅证明链路可行性；
  6. 全部数据来源与许可登记于 DATA_CATALOG.md。
