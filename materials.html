三、谱系核验（交付文件完整性）

谱系清单记录 183 个源文件 / 模型 / 产物的 SHA-256、生成顺序与软件版本；在仓库根目录执行：

python -m src.viz.lineage        # 生成/更新 reports/lineage.json
python -m src.viz.lineage --verify   # 逐项核验本地内容与清单一致

清单不证明源数据真实性，只证明"交付文件没有与记录脱节"；.gitattributes 统一 LF 检出，保证跨平台（Windows/Linux）核验一致。

启动：streamlit run deliverables/demo/app.py（离线可运行，无需网络）。

🔌 HTTP 预测服务（FastAPI）

严格模式（缺测即 422 拒绝）与容错模式（robust=true / /situation 三段提示）双轨：

import httpx
from src.models.forecast import load_koeln
df = load_koeln().iloc[-24:]
history = [{"time": t.isoformat(), **{k: float(v) for k, v in r.items()}}
           for t, r in df.iterrows()]
r = httpx.post("http://127.0.0.1:8000/forecast",
     json={"site": "koeln", "horizon_min": 60, "history": history})
print(r.json())   # issued_at / target_at / p10 / p50 / p90 / model_version

接口细节见 docs/接口说明.md；当前为离线回放/演示服务，未含身份认证与限流。
