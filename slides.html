背景 · 产业语境

上海排水管理体制改革 → "厂站网一体化"

  • 2025 年 4 月市政府印发改革方案：到 2026 年底，石洞口 / 竹园 / 白龙港三大片区实现厂站网一体化运维
  • 规模：744 万 m³/d（占全市约 70%），五大统一——含统一运行调度
  • 改革直面的问题：厂站网分离、运行效率不高；泵站放江污染突出、进水浓度偏低
  • 配套建设：排水感知体系及模拟评估系统（2026 年底）——本选题的直接语境
我们要做的，是"感知体系"里最前端的一段：把上游管网与泵站信号变成厂前进水的超前认知。
2 / 20
问题定义

厂前进水突变 = 工艺稳定的最大威胁

  • 合流制/截流式系统：降雨 → 管网入流入渗（RDII）→ 进厂流量数小时内成倍波动
  • 初期冲刷 + 雨水稀释 + 偷排冲击 → 进水 COD / 氨氮 / 毒性剧烈变化
  • 工艺调整存在小时级惯性——只能"事后响应"时，生化系统往往已经受损

机会在哪？水还没到、信号先到——上游管网节点距厂前 0.8~10.5 km，污水要走一段时间。

3 / 20
核心洞察

输送延迟 = 天然的超前量（0.3 ~ 3.6 小时）

τ = L / v：设计流速 0.8 m/s、距离 0.8~10.5 km → τ ≈ 0.3 ~ 3.6 小时

上游（t 时刻可观测）

管网关键节点液位 / 流量、泵站运行状态、降雨

厂前（t + τ 到达）

进水量、COD / 氨氮负荷 —— 我们要预测的目标

因果纪律：上游信号严格不含未来信息——零填充因果延迟路由 + 单元测试保证。

建模 · 防泄漏

特征工程与切分：先保证"不偷看未来"

  • 特征：滞后 {1,2,3,4,6,8,12,24} 步 + 一阶差分 + 6 步滚动均值 + 小时/星期 = 62 维
  • 发布时刻语义：t 只用 ≤t 的观测；目标为 t+h 真值；所有模型共用同一切分
  • 切分：时间顺序 75%/25%；训练末端再剔除 h 步（防标签跨界泄漏）
我们修过一个真实泄漏 bug：早期 np.roll 版本出现"提前量越长精度越高"的伪现象 → 改为零填充因果延迟 + 因果性单元测试。知道泄漏长什么样、怎么修、怎么防回归。

模型

LightGBM 主模型 + 四类基线对照

  • 主模型：LightGBM（400 棵 / lr 0.05 / 63 叶）+ 分位数 P10/P90（2×300 棵）
  • 对照：persistence（当前值）/ 季节朴素 / MLP(64-32) / LSTM（2 层×64、3h 窗口、5.2 万参数）
  • 选型理由：同精度档位更便宜（训练 3.3s vs 45.8s）、可解释（TreeSHAP）、原生支持缺测（容错基础）

边界

三条边界（主动声明）

① 模拟非实测

泰和为模拟场景；真实性能证据只有 Köln 等公开实测

② 区间未校准

P10–P90 覆盖率 67%~74%（名义 80%），不作保守上界

③ 未实厂率定

预警 / SWMM / 效益为概化与模拟推算，橙红无真实正例

展望

  • 申请上海政务"有条件开放"数据 → 实厂旁路验证
  • 区间校准 + 暴雨覆盖率专项 · 接入降雨数值预报与在线学习 · MPC 泵群优化调度

总结

一页话总结

  • 物理洞察：输送延迟 0.3~3.6h——上游信号是厂前的"预告片"
  • 数据方法论：真实数据验证方法（Köln 0.943/0.807/0.676）+ 官方骨架/实测降雨模拟场景（0.983/0.972/0.956）+ 物理模型在环
  • 工程闭环：四级预警 → 泵站建议 → SWMM 权衡（−28% / −89%）→ 容错（0.773）+ 监控回退 + 谱系（183 项）
  • 诚实边界：模拟非实测 · 区间未校准 · 未实厂率定——全部主动声明
